# 「그리스도」 id 자막 — 직역 역번역 (TB, _yv 306)

용어: Christ = Kristus(요 1:41 "Mesias (artinya: Kristus)") · Messiah = Mesias · **TB 마 16:16은 "Engkau adalah Mesias"(그리스도 자리에 Mesias)** → Q2/Q13 hl = "Mesias", 그래서 N09·N15(마 16장 흐름)도 Mesias로 맞춤 · 기름 부음 받은 자 = Yang Diurapi · 기름 붓다 = mengurapi(삼상 16:13 "mengurapi", 행 10:38 "mengurapi") · 기름 = minyak. '성' = nama belakang(뒷이름; 인도네시아에는 성이 없는 사람이 많아 '성' 대신 '뒷이름').

- N01: '예수 그리스도'라는 이름 속의 '그리스도' — / 그것은 예수의 뒷이름(성)인가?
- N02: 모든 기도 끝의 / 이름.
- N03: 그리스도는 뒷이름(성)이 아니다. / 뜻은 '기름 부음 받은 이' — 메시아.
- T1: 그리스도
- N04: 하나님은 왕, 제사장, 선지자를 세우셨다 / 기름으로 기름 부음을 통해.
- N06: 많은 사람들이 메시아를 기다렸다 / 오직 로마를 몰아낼 왕으로서만.
- N07: 어느 날, 예수께서 오신 뒤, / 베드로가 그의 고백을 말했다.
- N08: 그때부터 예수께서 말씀하셨다 / 자신이 고난받고 죽임을 당하고, / 셋째 날에 살아나야 한다고.
- N09: 베드로에게 죽는 메시아는 / 말이 되지 않았다.
- N10: 그러나 그 길은 / 이미 먼저 기록되어 있었다.
- N11: 십자가 위에서, / 예수의 부르짖음.
- N12: 이 부르짖음은 시편의 첫 줄이다 / 그보다 천 년 전에 쓰인 / 기름 부음 받은 왕 다윗에 의해.
- N14: 십자가 아래에서 군인들이 / 그분의 옷을 나누고 그분의 겉옷(jubah)을 두고 제비를 뽑았다.
- N20: 전에 "하나님께서 그 일을 멀리하시기를"(마 16:22 TB의 '그리 마옵소서')이라고 말했던 베드로가, / 부활하신 예수를 만난 뒤, 이것을 전했다:
- N15: 고난받는 메시아는 실패가 아니라, / 성경이 가리킨 길이다.
- N16K: 왕,
- N16P: 제사장,
- N16R: 선지자,
- N16: 세 직분이, / 한 인격 안에.
- N17: '그리스도'는 뒷이름(성)이 아니라, / 고백이다 / 예수가 바로 그 메시아라는.
