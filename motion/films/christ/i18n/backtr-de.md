# 「그리스도」 de (Luther 1912) — 직역 역번역 (자막 범위)

| id | de | 직역 |
|---|---|---|
| N01 | Das „Christus“ in „Jesus Christus“ – / ist das der Nachname von Jesus? | '예수 그리스도' 안의 '그리스도' — / 그것이 예수님의 성인가요? |
| N02 | Der Name am Ende / jedes Gebets. | 모든 기도 끝에 있는 / 그 이름. |
| N03 | Christus ist kein Nachname. / Es bedeutet „der Gesalbte“ – der Messias. | 그리스도는 성이 아닙니다. / '기름 부음 받은 자' — 메시야라는 뜻입니다. |
| T1 | Christus | 그리스도 |
| N04 | Gott setzte Könige, Priester und Propheten ein, / indem er sie mit Öl salbte. | 하나님은 왕과 제사장과 선지자를 세우셨습니다, / 그들에게 기름을 부으심으로. |
| N06 | Viele erwarteten den Messias / nur als König, der Rom vertreiben würde. | 많은 이들은 메시야를 / 로마를 몰아낼 왕으로만 기다렸습니다. |
| N07 | Eines Tages, nachdem Jesus gekommen war, / legte Petrus ein Bekenntnis ab. | 예수님이 오신 뒤 어느 날, / 베드로가 고백을 했습니다. |
| N08 | Von da an sagte Jesus, / er müsse leiden und getötet werden / und am dritten Tag auferstehen. | 그때부터 예수님은 / 고난받고 죽임을 당하고 / 제삼일에 살아나야 한다고 말씀하셨습니다. |
| N09 | Ein Christus, der stirbt – / das ergab für Petrus keinen Sinn. | 죽는 그리스도 — / 그것은 베드로에게 말이 안 됐습니다. |
| N10 | Doch dieser Weg / stand schon geschrieben. | 그런데 그 길은 / 이미 적혀 있었습니다. |
| N11 | Am Kreuz – / der Schrei Jesu. | 십자가 위에서 — / 예수님의 외침. |
| N12 | Dieser Schrei ist die erste Zeile eines Psalms, / tausend Jahre zuvor geschrieben / von David, dem gesalbten König. | 이 외침은 시편의 첫 줄입니다, / 천 년 전에 쓰인, / 기름 부음 받은 왕 다윗이 쓴. |
| N14 | Unter dem Kreuz teilten die Soldaten / seine Kleider und warfen das Los um sein Gewand. | 십자가 아래에서 군인들은 / 그의 옷을 나누고 그의 겉옷을 두고 제비를 뽑았습니다. |
| N20 | Petrus, der einst gesagt hatte: „Schone dein selbst“, / predigte, nachdem er dem auferstandenen Jesus begegnet war: | 한때 '그리 마옵소서(자신을 아끼소서)'라고 했던 베드로가 / 부활하신 예수님을 만난 뒤 전했습니다: |
| N15 | Der leidende Christus war kein Scheitern – / er war der Weg, auf den die Schrift hinwies. | 고난받는 그리스도는 실패가 아니었습니다 — / 성경이 가리킨 길이었습니다. |

| N16 | drei Ämter, / in einer Person. | 세 직분이, / 한 분 안에. |
| N17 | „Christus“ ist kein Nachname. / Es ist das Bekenntnis, / dass Jesus genau dieser Messias ist. | '그리스도'는 성이 아닙니다. / 예수님이 바로 그 메시야라는 / 고백입니다. |

참고: 루터 1912 요 1:41은 "Messias … (verdolmetscht: der Gesalbte)" — '그리스도' 대신 '기름 부음 받은 자'로 풀어 씀. N03이 바로 이 짝(Messias = der Gesalbte)을 씀; Christus는 마 16:16. 마 16:22 "HERR, schone dein selbst"(직역 "주여, 자신을 아끼소서")가 "그리 마옵소서"에 해당.
