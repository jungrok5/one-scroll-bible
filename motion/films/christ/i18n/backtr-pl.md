# 「그리스도」 pl 자막 — 직역 역번역 (Biblia Gdańska, _yv 132)

용어: Christ = Chrystus · Messiah = Mesyjasz(Gdańska 요 1:41 표기) · 기름 부음 받은 자 = Pomazaniec · 기름 붓다 = pomazać(삼상 16:13 "pomazał", 행 10:38 "pomazał") · 기름 = oliwa(삼상 16:13 "z oliwą")

- N01: '예수 그리스도'라는 이름 속의 '그리스도' — / 그것은 예수의 성(姓)인가?
- N02: 끝에 있는 이름 / 모든 기도의.
- N03: 그리스도는 성이 아니다. / 그것은 '기름 부음 받은 자'를 뜻한다 — 메시야.
- T1: 그리스도
- N04: 하나님은 왕들과 제사장들과 선지자들을 세우셨다, / 그들에게 기름(올리브기름)을 부으시며.
- N06: 많은 사람들이 메시야를 기다렸다 / 오직 로마 사람들을 쫓아낼 왕으로서만.
- N07: 어느 날, 예수께서 이미 오신 뒤, / 베드로가 고백을 했다.
- N08: 그때부터 예수께서는 말씀하셨다, / 고난받고 죽임을 당해야 하며, / 셋째 날에 죽은 자 가운데서 살아나야 한다고.
- N09: 베드로에게 죽는 그리스도는 / 말이 되지 않았다.
- N10: 그러나 그 길은 / 이미 기록되어 있었다.
- N11: 십자가 위에서 — / 예수의 외침.
- N12: 이 외침은 시편의 첫 줄이다, / 천 년 앞서 쓴 / 기름 부음 받은 왕 다윗이.
- N14: 십자가 아래에서 군인들이 / 그분의 옷을 나누고, 그분의 속옷을 두고 제비를 던졌다.
- N20: 한때 "스스로를 불쌍히 여기소서"(마 16:22 Gdańska의 '그리 마옵소서')라고 말하던 베드로가, / 부활하신 예수를 만난 뒤 이렇게 전했다:
- N15: 고난받는 그리스도는 실패가 아니었다 — / 성경이 가리킨 길이었다.
- N16K: 왕,
- N16P: 제사장,
- N16R: 선지자,
- N16: 세 직분이 / 한 인격(분) 안에.
- N17: '그리스도'는 성이 아니다. / 그것은 고백이다, / 예수가 바로 그 메시야라는.
