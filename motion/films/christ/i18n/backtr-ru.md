# 「그리스도」 ru 자막 — 직역 역번역 (Синодальный, _yv 400)

용어: Christ = Христос · Messiah = Мессия(요 1:41 "мы нашли Мессию, что значит: Христос") · 기름 부음 받은 자 = Помазанник · 기름 붓다 = помазать(삼상 16:13 "помазал", 행 10:38 "помазал") · 기름 = елей

- N01: '예수 그리스도'라는 이름 속의 '그리스도' — / 이것은 예수의 성(姓)인가?
- N02: 이름, 그것으로 끝나는 / 모든 기도가.
- N03: 그리스도 — 성이 아니다. / 이것은 '기름 부음 받은 자(Помазанник)', 메시야라는 뜻이다.
- T1: 그리스도
- N04: 하나님은 왕들과 제사장들과 선지자들을 세우셨다, / 그들에게 기름(елей)을 부으시며.
- N06: 많은 이들이 메시야를 기다렸다 / 오직 로마인들을 쫓아낼 왕으로서만.
- N07: 어느 날, 예수께서 이미 오셨을 때, / 베드로가 자기 믿음을 고백했다.
- N08: 그때부터 예수께서 말씀하셨다, / 그분이 고난받고 죽임을 당해야 하며 / 셋째 날에 부활해야 한다고.
- N09: 베드로에게 죽어 가는 그리스도는 / 아무 의미가 없었다(말이 안 됐다).
- N10: 그러나 이 길은 / 이미 기록되어 있었다.
- N11: 십자가 위에서 — / 예수의 부르짖음.
- N12: 이 부르짖음은 시편의 첫 줄이다, / 그보다 천 년 전에 쓰인 / 기름 부음 받은 왕 다윗에 의해.
- N14: 십자가 곁에서 군인들이 / 그분의 옷들을 나누고, 속옷(хитон)을 두고 제비를 던졌다.
- N20: 한때 "주여, 자신을 아끼소서"(마 16:22 Синод.의 '그리 마옵소서')라고 말했던 베드로가, / 부활하신 예수를 만나고 나서, 이렇게 전했다:
- N15: 고난받는 그리스도는 패배가 아니다, / 성경이 가리킨 길이다.
- N16K: 왕,
- N16P: 제사장,
- N16R: 선지자,
- N16: 세 직분(служения) — / 한 위격(Лице) 안에.
- N17: '그리스도'는 성이 아니다, / 고백이다, / 예수가 바로 그 메시야라는.
