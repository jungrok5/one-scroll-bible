# 「그리스도」 th (ฉบับมาตรฐาน) — 직역 역번역

- T1 พระคริสต์ — 그리스도
- N01 คำว่า “คริสต์” ในพระนาม “พระเยซูคริสต์” / เป็นนามสกุลของพระเยซูหรือ? — '예수 그리스도'라는 이름 속 '그리스도'라는 말은 / 예수의 성(นามสกุล)일까요?
- N02 พระนามที่อยู่ในตอนท้าย / ของทุกคำอธิษฐาน — 모든 기도의 / 끝에 있는 그 이름(존칭).
- N03 พระคริสต์ไม่ใช่นามสกุล / แต่หมายถึง “ผู้ที่ได้รับการเจิม” คือพระเมสสิยาห์ — 그리스도는 성이 아닙니다 / '기름 부음 받은 자', 곧 메시야라는 뜻입니다.
- N04 พระเจ้าทรงเจิมด้วยน้ำมัน / เพื่อแต่งตั้งกษัตริย์ ปุโรหิต และผู้เผยพระวจนะ — 하나님은 기름으로 부으셨습니다 / 왕, 제사장, 그리고 선지자(말씀을 전하는 자)를 세우시려고.
- N06 คนจำนวนมากรอคอยพระเมสสิยาห์ / เพียงในฐานะกษัตริย์ที่จะขับไล่โรมออกไป — 많은 사람이 메시야를 기다렸습니다 / 로마를 몰아낼 왕으로서만.
- N07 วันหนึ่ง หลังจากที่พระเยซูเสด็จมาแล้ว / เปโตรได้ประกาศความเชื่อของเขา — 어느 날, 예수께서 오신 뒤에 / 베드로가 자기의 믿음을 선포(고백)했습니다.
- N08 ตั้งแต่นั้นมา พระเยซูตรัสว่า / พระองค์จะต้องทรงทนทุกข์และถูกประหารชีวิต / แล้วในวันที่สามจะทรงเป็นขึ้นมาใหม่ — 그때부터 예수께서 말씀하셨습니다 / 자신이 고난을 받고 죽임을 당해야 하며 / 셋째 날에 다시 살아나실 것이라고.
- N09 สำหรับเปโตร พระคริสต์ที่ต้องสิ้นพระชนม์ / เป็นเรื่องที่ไม่สมเหตุสมผลเลย — 베드로에게, 죽으셔야 하는 그리스도는 / 전혀 말이 안 되는 일이었습니다.
- N10 แต่หนทางนั้น / ได้ถูกเขียนไว้แล้ว — 그러나 그 길은 / 이미 적혀 있었습니다.
- N11 บนกางเขน / เสียงร้องของพระเยซู — 십자가 위, / 예수의 외침.
- N12 เสียงร้องนี้คือบรรทัดแรกของบทสดุดี / ที่ดาวิด กษัตริย์ผู้ได้รับการเจิม / เขียนไว้เมื่อพันปีก่อน — 이 외침은 시편의 첫 줄입니다 / 기름 부음 받은 왕 다윗이 / 천 년 전에 쓴.
- N14 ใต้กางเขน พวกทหาร / แบ่งเสื้อของพระองค์ และจับฉลากเสื้อในของพระองค์ — 십자가 아래서 군인들이 / 그분의 옷을 나누고, 그분의 속옷을 두고 제비를 뽑았습니다.
- N20 เปโตรผู้เคยกล่าวว่า “อย่าให้เป็นเช่นนั้น” / หลังจากได้พบพระเยซูผู้ทรงเป็นขึ้นจากตาย ได้ประกาศเรื่องนี้ว่า — "그렇게 되지 않게 하소서(그리 마옵소서)"라고 했던 베드로가 / 죽은 자 가운데서 살아나신 예수를 만난 뒤, 이것을 이렇게 전했습니다.
- N15 พระคริสต์ผู้ทรงทนทุกข์ไม่ใช่ความล้มเหลว / แต่เป็นหนทางที่พระคัมภีร์ได้ชี้ไว้ — 고난받으신 그리스도는 실패가 아니라 / 성경이 가리켜 둔 길입니다.
- N16K กษัตริย์ — 왕
- N16P ปุโรหิต — 제사장
- N16R ผู้เผยพระวจนะ — 선지자
- N16 สามตำแหน่ง / ในพระองค์เดียว — 세 직분이 / 한 분 안에.
- N17 “พระคริสต์” ไม่ใช่นามสกุล / แต่เป็นการยอมรับความเชื่อว่า / พระเยซูคือพระเมสสิยาห์องค์นั้น — '그리스도'는 성이 아니라 / 믿음으로 고백하는 것입니다 / 예수께서 바로 그 메시야이심을.
