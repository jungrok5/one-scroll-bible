# 「그리스도」 tl (MBB) — 해설 직역 역번역

- T1 Cristo — 그리스도
- N01 “Jesu-Cristo”의 “Cristo” — / 그것은 예수님의 성(姓)입니까?
- N02 모든 기도 끝에 있는 / 그 이름.
- N03 그리스도는 성이 아닙니다. / 그 뜻은 “기름 부음을 받은 자(기름을 부어 받은 자)” — 메시야입니다.
- N04 하나님은 왕들과 제사장들과 선지자들을 세우셨습니다(구별하셨습니다) / 그들에게 기름을 부으심으로.
- N06 많은 사람이 메시야를 기다렸습니다 / 로마를 몰아낼 왕으로만.
- N07 어느 날, 예수님이 오신 뒤에, / 베드로가 자기 믿음을 고백했습니다.
- N08 그때부터 예수님은 말씀하셨습니다 / 자신이 고난받고 죽임당해야 하며, / 사흘째 되는 날 다시 살아나야 한다고.
- N09 베드로에게는 말이 안 되었습니다 / 죽을 그리스도라는 것이.
- N10 그러나 그 길은 / 이미 오래전에 기록되어 있었습니다.
- N11 십자가에서, / 예수님의 외침.
- N12 이 외침은 한 시편의 첫 줄입니다 / 예수님보다 천 년 전에 쓰인 / 기름 부음 받은 왕 다윗이 (쓴).
- N14 십자가 발치에서 군인들이 그분의 옷들을 나누어 가졌고 / 그분의 겉옷(의복)을 걸고 내기(제비)를 했습니다.
- N20 한때 “하나님께서 허락하지 마시기를(그리 마옵소서)!” 하고 말했던 베드로가, / 다시 살아나신 예수님을 만난 뒤에 이렇게 전했습니다:
- N15 고난받은 그리스도는 실패가 아닙니다 — / 그것은 성경이 가리킨 길이었습니다.
- N16K 왕,
- N16P 제사장,
- N16R 선지자,
- N16 세 직분이, / 한 위격(한 분) 안에.
- N17 “그리스도”는 성이 아닙니다. / 그것은 고백입니다 / 예수님 바로 그분이 그 메시야라는.

메모: MBB 사도행전 10:38에는 "기름 붓다" 동사가 없음("pinili siya ng Diyos … pinuspos ng Espiritu Santo" = 하나님이 그를 택하시고 성령으로 충만케 하셨다) → Q9 hl = "pinuspos ng Espiritu Santo". N03·N04·N12의 "기름 부음"은 MBB 삼상 16:13·레 8:12·왕상 19:16의 동사 "buhusan/binuhusan ng langis"(기름을 붓다)로 맞춤. 제사장 = Saserdote(사이트 팩 용어; MBB 인용 구절엔 없음).
