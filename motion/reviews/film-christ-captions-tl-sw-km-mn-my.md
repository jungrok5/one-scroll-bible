# 「그리스도」 자막 원어민 검수 — tl · sw · km · mn · my

검수일 2026-11-15. 검수자 관점: 각 언어 원어민 복음주의·개혁주의 성경 교사, 대상 성경을 잘 모르는 55세 이상 그리스도인
(km·mn·my는 한국에 사는 이주민 포함). 보고만 함 — 언어 파일은 고치지 않음.

기준: `motion/films/christ/script.json`(한국어 원문), `i18n/en.json`(검수된 영어 의미), `i18n/CAPTIONS-BRIEF.md`,
각 `backtr-<code>.md`, 사이트 팩 `i18n/<code>.json`.

## 공통 확인

- `node motion/films/check-quotes.mjs christ <code>` — **5개 언어 모두 15개 인용 전부 `ok`** (my Q1은 `JHN.1.41-42`).
- 숫자: 다섯 사이트 팩 모두 장절에 아라비아 숫자를 씀(km·my 팩도 cite는 `1:1` 형식) → 자막 cite의 아라비아 숫자가 맞음.
  해설에는 숫자가 없음(“천 년”은 모두 글자로 씀).
- 성(姓) 질문 N01/N03/N17: 다섯 언어 모두 “성/집안 이름” 단어를 바르게 골라 질문 → 답 → 마지막 확인 구조가 살아 있음
  (tl apelyido · sw jina la ukoo · km នាមត្រកូល · mn овог · my မျိုးရိုးအမည်).
- 그리스도 = 메시야 = 기름 부음 받은 자: sw·km·mn·my는 N03·N04·N12의 “기름 부음” 말이 삼상 16:13·왕상 19:16·행 10:38의 동사와
  같아서 연결이 화면에 보임. tl만 행 10:38(MBB)에 “기름 붓다”가 없어 마지막 연결 고리가 약함(아래 tl 참조).

심각도: HIGH = 뜻이 틀리거나 신학적으로 잘못 · MED = 빠짐/어긋남/용어 불일치로 요점이 약해짐 · LOW = 다듬기(선택).
