## 매일 19:12 — 댓글 관리

cron `12 19 * * *` (KST)

```text
[예약 작업 — 한국어 쇼츠 '다음 편' 고정 댓글 + 모든 채널 새 댓글 관리] (1) YT_* 사용자 환경 변수(YT_CLIENT_ID·YT_CLIENT_SECRET·YT_REFRESH_TOKEN·YT_REFRESH_TOKEN_GLOBAL)를 불러와 `node motion/youtube/ko-next-comment.mjs today` 실행 — 주일이면 "오늘 공개 없음"이 나오고 (3)은 건너뛴다. 공개 전이면 몇 분 뒤 한 번 더. (2) 크롬의 유튜브 신원이 국제 채널로 바뀌어 있을 수 있으니 먼저 youtube.com/channel_switcher 에서 '한눈에 보는 성경 이야기 @one-scroll-bible'을 실제 클릭으로 고른다. (3) 출력된 watch 링크를 열고, 한국어 채널 댓글의 ⋮ → 고정 → 확인 대화상자의 '고정'을 실제 클릭(find ref)으로 누른 뒤 고정 배지 확인. (4) 새 댓글 — 모든 채널·플랫폼의 모든 영상: 한국어 유튜브 `node motion/youtube/yt-api.mjs comments`, 국제 유튜브 같은 명령에 환경 변수 YT_AS=GLOBAL, 인스타그램은 instagram.com/one.scroll.bible 최근 릴스의 댓글, 스레드는 threads.com 활동의 답글(모두 브라우저). motion/README.md "댓글 관리" 기준으로 **좋아요·하트는 직접 누른다**(관리자 결정 2026-11-01; 하트 = 채널 동의 표시 — 무관한 교리·종말 시나리오 붙여넣기에는 하트 없음; 유튜브는 해당 채널 신원으로, 국제 채널 댓글은 channel_switcher에서 Bible in One Scroll로 바꿨다가 끝나면 한국어 채널로 되돌린다). @jungrok5 댓글은 뺀다. 답글은 달지 않고 초안도 만들지 않는다. 숨기기·삭제는 하지 않고, 정말 그럴 만한 댓글(반복 도배·링크/포교·욕설·스팸)이 있을 때만 알린다. (5) 결과(몇 편, 댓글 id, 고정 여부 + 플랫폼별로 좋아요·하트 누른 것 / 안 누른 것 / 숨기기·삭제 제안)를 한국어로 짧게 보고. 21편(11/16)까지 끝나면 '다음 편' 부분은 끝났다고 알리고 댓글 관리는 계속할지 물어봐 줘. 다른 게시·삭제·수정은 하지 말 것.
```
